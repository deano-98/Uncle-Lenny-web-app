# Uncle Lenny School Run Services — Next.js 16 Mock

Premium, responsive brochure/lead-generation website mock for a Harare school transportation business.

## Stack
- Next.js 16 + App Router
- React 19
- TypeScript
- Tailwind is intentionally not required in this mock; styling is in `app/globals.css`
- Lucide React icons
- WhatsApp-first conversion flow

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

For production:

```bash
npm run build
npm start
```
